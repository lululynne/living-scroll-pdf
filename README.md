# 卷轴PDF · Living Scroll PDF

**中文** | [English](README.en.md)

英文名 Living Scroll PDF：scroll 在英文里既是「卷轴」也是「滚动」，卷轴PDF 做的就是边滚动边把聊天收成一卷。

macOS 上的滚动长截图工具：**钉住一个窗口，框出区域，你一边滚，它一边截**，自动拼成一张长图，存成 PDF + PNG，并附一份带时间和 SHA-256 的记录文件。

做它的起因：越来越多的工作发生在云端 agent 里（网页里的智能体、云电脑 bot），它们没有可导出的原始日志，只有一页聊天记录。提示词、生成过程、来回修改的经过，想原样留档时，一屏一屏截图再拼太累，复制粘贴又会丢掉图片和排版。卷轴PDF 把整段对话原样截成一份 PDF，连同记录文件一起——留作创作过程的存证、项目交接、或者单纯存档都行。不少 AI 创作类征集活动会要求提交原始创作记录，这也是它的用处之一。

## 它和普通"滚动截图"有什么不同

- **按窗口截，不按屏幕截。** 用 ScreenCaptureKit 只抓选中的那个窗口自己的画面：别的窗口压在上面、截取框和控制条本身，都不会进到图里。窗口被拖动，红框跟着走。
- **你手动滚就行。** 每 0.12 秒取一帧，算出内容移动了多少像素，只把新露出来的行接上去。往回滚、停下、快慢不一都没关系。也可以点「自动滚到底」让它自己滚，滚不动了自动收尾。
- **专门对付聊天界面：**
  - 顶部固定的标题栏、底部固定的输入框只出现一次，不会每段重复；
  - 输入框里闪烁的光标、滚动条滑块的淡入淡出不会被当成内容；
  - 正常滚动速度下，浮在内容上的「回到最新」按钮、窗口圆角只出现在最末尾，不会出现在每个接缝处（一次滚过将近一整屏时，按钮可能留在中间）；
  - 区域被竖切成多条分别对齐，局部变化（滚动条、侧栏头像）不会让整段对不上；
  - 真的滚太快、对不上时，这一张不收，状态栏提示往回滚一点，滚回来就自动接上；绝不硬贴、不重复。截图结束时还没接回来，文件名会带「未完成」。
- **输出适合存档：** 每次同时存一张 PNG 长图和一份 PDF。PDF 默认是一整页长 PDF，和长图一样从头到尾没有分页缝（超过 200 英寸的 PDF 页面上限时才在空白行处续页）；菜单「PDF 页面」里可以改成按 A4 比例分页，方便打印，分页同样尽量切在空白行，不把字切成两半；同名 `.json` 记录应用名、窗口标题、开始/结束时间、帧数、拒收帧数、是否未完成，以及 PNG 和 PDF 的 SHA-256。

关于存证：SHA-256 能证明文件和你截取时生成的是同一份，前提是这串值另外存在别处（比如截完立刻发给对方、存进邮件或别的系统）。只看同一文件夹里的 `.json` 证明不了什么——改了图再重算一遍就对得上。卷轴PDF 也不对时间和窗口信息做签名认证。

## 用法

1. 运行 `./build-app.sh`，得到 `dist/Living Scroll PDF.app`，拖进「应用程序」后打开。菜单栏出现一个卷轴图标。
2. 第一次打开时在 **系统设置 › 隐私与安全性 › 屏幕与系统录音** 里打开「卷轴PDF」，然后重开一次。
3. 按 **⌃⌥S**（或点菜单栏「卷」→ 开始截取）：
   - 鼠标移到要截的窗口上，蓝框高亮，点一下选中；
   - 在窗口里拖出要截的区域（只框聊天内容最准）；直接点一下 = 整个窗口；Esc 返回/取消；
   - 红色虚线框出现后，正常滚动那个窗口；
   - 点「完成」（或再按一次 ⌃⌥S），PDF 自动打开，文件在 `桌面/卷轴PDF/`。
4. 「自动滚到底」需要额外在 **辅助功能** 里打开卷轴PDF。自动滚动前会先确认滚轮落点下面就是目标窗口，被挡住会自动暂停，不会滚到别的窗口里。

目前只支持往下滚（从对话开头截到结尾）。需要 macOS 14 或更新版本。界面有中文和英文，默认跟随系统语言，菜单「界面语言」里可以切换。

## 开发

```sh
swift build -c release
.build/release/LivingScrollPDF selftest   # 合成聊天界面逐像素自测
./build-app.sh                     # 打包 .app（ad-hoc 签名）
```

自测会构造带固定标题栏、带闪烁光标的输入框、移动的滚动条、浮动按钮、透明圆角的帧序列，用不规则的步长和回滚喂给拼接器，再和原图逐像素比对。

`Sources/LivingScrollPDF/` 里：`Stitcher.swift` 拼接核心，`CaptureSession.swift` 截取循环和控制条，`WindowPicker.swift` 选窗口和框选，`Exporter.swift` 导出 PDF/PNG/记录。
